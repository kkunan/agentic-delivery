Round-Up Test Cases

The cases we ran on the iPhone simulator before the round-up branch merges. Pocket Goal is a made-up savings app. With round-ups on, each card payment rounds up to the next whole dollar, and the difference goes to a savings goal. Each case names what we do, what the user must see, and the result. Five cases pass, one fails, and the gate owner waived one.

tally: 7 checks, 6 run, 0 unrun, 1 waived app 2.4.0 (41) iOS simulator staging API

Setup

App
Debug build 2.4.0 (41) from the feature branch, on the iPhone 16 simulator.
Backend
The staging API. A card stub sends the card payments, and a test clock moves the time.
Account
A test account with one goal, "Holiday fund", target 200.00, balance 500.00.
Proof
A screenshot of each step, the push log of the staging API, and the email log for the receipt.

A round-up is the difference between a card payment and the next whole dollar. A payment of 3.40 gives a round-up of 0.60.
