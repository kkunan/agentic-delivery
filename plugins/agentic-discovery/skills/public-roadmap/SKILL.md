# Public roadmap

Load the skill `public-writing` first. Its rules cover every word of the page.

1. Read `questions.md`. It gives the page, section by section, and the questions that fill each section.
2. Ask the owner the questions, one in each message. Mark each gap that stays open.
3. Copy `template.html`, and replace each `{{placeholder}}` with the words of the owner.
4. Look at a file in `samples/` to see a finished page. All three products in the samples are made up.
5. Read the draft against the list at the end of `questions.md`. Then give it to the owner for comments.
